## 흐름 (주 1회 또는 격주)
1. **선정**: `v_picks`에서 분야별(장보기·패션·뷰티) 상위 상품을 고른다. 몰당 최대 2개, 이미지 있는 것만,
   **게시일+7일 이후까지 판매가 유지되는 상품 우선**(오늘 마감 상품은 영상이 나갈 때 이미 끝나 있음).
   주 10편 = 분야별 3~4편.
2. **대본(무료)**: 이름·가격·할인율·검색량·마감일 등 DB 실측값만 쓴다. 써 본 듯한 후기, 효능·효과 주장, 별점은 넣지 않는다.
   (표시광고법·화장품법 위험 + 실제 리뷰가 아닌 것을 리뷰처럼 보이게 하면 안 됨)
3. **힉스필드(유료, 1편당 1회 호출)**: 공식 상품 사진을 시작 프레임으로 5초 클립 1개.
   모델 `kling3_0_turbo` 720p 5초 = **7.5크레딧/편**(10편 75크레딧/주). 이미지 생성·음성·업스케일은 쓰지 않는다.
4. **합성(무료)**: `compose.py spec.json` — 후킹 카드 2.5초 → AI 클립 5초(상품명·선정 이유 자막) → 가격 카드 3초 → CTA 2초 = 12.5초, 720x1280 30fps.
   한글 폰트 Noto Sans KR. 'AI로 만든 영상', '가격은 수집 시점 기준' 문구 고정.
5. **게시**: 영상은 Supabase Storage `shorts` 버킷, 목록은 `weekly_shorts` 테이블 → 각 사이트 오른쪽 레일 '이번 주 숏폼'.
   (유튜브 쇼츠·인스타 릴스 업로드는 계정 연결 후 별도)
